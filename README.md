AI Code-to-Visual Converter is an interactive educational web app designed to bridge the gap between raw code syntax and logic comprehension.

It automatically parses Python and SQL scripts, transforming them into dynamic visual flowcharts with step-by-step logic simulation and dual-language explanations
.ynamic Flowchart Generation: 
Automatically parses Python & SQL code into interactive SVG flowcharts.

Step-by-Step Logic Simulator: Highlights active code lines and diagram nodes simultaneously during execution.
Dual-Language Explanations: Real-time step breakdowns in both English and Roman Urdu for accessible learning.
 Prebuilt Snippet Library: Ready-to-run examples covering Loops, Conditional Logic (If-Else), and SQL JOINs.
 Gemini AI Integration: Provides deep structured explanations for custom complex code snippets.
